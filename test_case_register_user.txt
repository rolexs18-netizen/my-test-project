Название: Успешная регистрация пользователя через API
Предусловие: Сервер dummyjson.com доступен, таблица users_dummy существует
Шаги:
1. Отправить POST-запрос на https://dummyjson.com/users/add с телом {"firstName": "Иван", "lastName": "Петров", "email": "ivan@example.com", "password": "secret123"}
2. Убедиться, что статус-код ответа 200 или 201
3. Проверить, что в ответе есть поле id со значением 209 и поле firstName со значением "Иван"
4. Выполнить SQL-запрос SELECT email FROM users_dummy WHERE email = 'ivan@example.com'
5. Убедиться, что запрос возвращает строку с этим email
Ожидаемый результат: Пользователь создан, id=209, firstName="Иван", email существует в базе данных
