## Тест-кейс 1: Успешное удаление отзыва

**Цель:** Проверить, что пользователь может удалить свой ранее оставленный отзыв.

**Предусловия:**
- Пользователь bob авторизован (token: tok_bob).
- Товар с prod_id=1 существует.
- В таблице ratings есть запись от bob для prod_id=1 с rating=2 и review="так себе" (rating_id=2).

**Шаги:**
1. Отправить DELETE-запрос на /deletereview с телом:
   { "user_token": "tok_bob", "prod_id": 1 }
2. Проверить статус-код ответа и тело ответа.
3. Выполнить SQL-запрос для проверки отсутствия записи:
   SELECT COUNT(*) FROM ratings JOIN users ON ratings.user_id = users.user_id WHERE username = 'bob' AND prod_id = 1;

**Ожидаемый результат:**
- Статус-код: 200 OK.
- Тело ответа: пустое.
- SQL (COUNT): 0.


## Тест-кейс 2: Удаление несуществующего отзыва

**Цель:** Проверить, что при попытке удалить отзыв, которого нет, API возвращает ошибку 404 Not Found.

**Предусловия:**
- Пользователь alice авторизован (token: tok_alice).
- Товар с prod_id=2 существует.
- В таблице ratings отсутствует запись от alice для prod_id=2.

**Шаги:**
1. Отправить DELETE-запрос на /deletereview с телом:
   { "user_token": "tok_alice", "prod_id": 2 }
2. Проверить статус-код ответа.
3. Выполнить SQL-запрос для подтверждения, что запись не появилась:
   SELECT COUNT(*) FROM ratings JOIN users ON ratings.user_id = users.user_id WHERE username = 'alice' AND prod_id = 2;

**Ожидаемый результат:**
- Статус-код: 404 Not Found.
- Тело ответа может содержать сообщение об ошибке (формат уточняется).
- SQL (COUNT): 0 (запись отсутствует).
