Название: API /addtocart с flag=true возвращает ошибку "Bad parameter, token malformed"

Окружение:

Postman

URL: https://api.demoblaze.com/addtocart

Куки пользователя: user=2da16450-2260-ccc5-6401-c7831e329e25

Предусловия:

Получен валидный токен id из успешного запроса в корзину (flag=false): 240e3a02-4a54-83b2-b45f-8eff5c104b47

Используется та же пользовательская сессия

Шаги воспроизведения:

Открыть Postman, создать POST-запрос на https://api.demoblaze.com/addtocart

Указать тело (raw JSON):

json
{
  "id": "240e3a02-4a54-83b2-b45f-8eff5c104b47",
  "cookie": "user=2da16450-2260-ccc5-6401-c7831e329e25",
  "prod_id": 1,
  "flag": true
}
Отправить запрос

Фактический результат:

Статус-код: 200 OK

Тело ответа: {"errorMessage": "Bad parameter, token malformed."}

Ожидаемый результат:

Статус-код: 200 OK или 201 Created

Тело ответа: пустое (или {}) — как при успешном добавлении в корзину

В базе данных в таблице wishlist появляется запись для user_id=101 и prod_id=1

Серьёзность: Блокирующая (функционал избранного недоступен через API, обходного пути нет)

Дополнительно:

Тот же токен работает с flag=false (корзина)

Удаление поля id или подстановка невалидного токена приводит к такой же ошибке
