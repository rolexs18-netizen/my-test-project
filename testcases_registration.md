## Тест-кейс 1: Успешная регистрация с валидными данными
**Предусловия:** форма регистрации доступна, email `userlina@domain.com` не занят.
**Шаги:**
1. Ввести имя: `lina`
2. Ввести email: `userlina@domain.com`
3. Ввести пароль: `Lina12345678`
4. Нажать кнопку «Зарегистрироваться»
**Ожидаемый результат:**
- Пользователь зарегистрирован.
- В БД в таблице users появилась запись с username='lina' и email='userlina@domain.com'.

## Тест-кейс 2: Поле Имя — граничные значения длины
**Предусловия:** форма регистрации доступна.
**Шаги:**
1. Проверить границу 2 символа (невалид): ввести имя `Al`, остальные поля валидны.
2. Проверить границу 3 символа (валид): ввести имя `Ali`, остальные поля валидны.
3. Проверить границу 20 символов (валид): ввести имя из 20 латинских букв, остальные поля валидны.
4. Проверить границу 21 символ (невалид): ввести имя из 21 символа, остальные поля валидны.
**Ожидаемый результат:**
- Для шагов 1 и 4: сообщение об ошибке у поля Имя, регистрация не происходит.
- Для шагов 2 и 3: успешная регистрация (email каждый раз новый).

## Тест-кейс 3: Поле Имя — невалидный класс (спецсимволы и пробел)
**Предусловия:** форма доступна.
**Шаги:**
1. Ввести имя с пробелом: `li na`, email и пароль валидные.
2. Ввести имя со спецсимволом: `lina!`, email и пароль валидные.
**Ожидаемый результат:** сообщение об ошибке у поля Имя, регистрация не происходит.
